# OpenProject Bug Extractor Plan

## Goal
Extract all bugs from OpenProject project `dom-zhkkh` with ID and Title, save as CSV.

## Project Structure
```
openproject-extractor/
├── .env                    # API token storage
├── requirements.txt        # Python dependencies
├── src/
│   └── extractor.py        # Main extraction script
├── output/                  # CSV output directory
├── tests/
│   └── test_extractor.py   # Unit tests
├── Makefile                # Pipeline commands
└── README.md               # Documentation
```

## API Details
- **Base URL**: `https://projects-customdev.wone-it.ru`
- **Endpoint**: `/api/v3/projects/dom-zhkkh/work_packages`
- **Authentication**: Bearer token (API key) via `Authorization` header
- **Filter**: Type = "Bug" (case-sensitive, may need adjustment based on OpenProject locale)

## Implementation Steps

### 1. Environment Setup
- Create `.env` file with `OPENPROJECT_API_TOKEN=<token>`
- Create `requirements.txt` with dependencies:
  - `requests` - HTTP client
  - `python-dotenv` - env file loading
  - `python-dateutil` - datetime parsing

### 2. Main Script (`src/extractor.py`)
- Load API token from `.env` (key: `OPENPROJECT_API_TOKEN`)
- Make paginated GET request to work packages endpoint
- Filter by type "Bug" (using query filter: `filters=[{"type":{"operator":"=","values":["Bug"]}}]`)
- Extract `id` and `subject` (title) from each work package
- Handle pagination (look for `_embedded.elements` array and `._links.next`)
- Save to CSV with `;` separator: `output/res-<datetime>.csv`
- Handle errors: HTTP 401 (invalid/missing token), HTTP 404 (project not found), network errors

### 3. Output Format
- File: `output/res-YYYY-MM-DD_HH-MM-SS.csv`
- Columns: `id;title`
- CSV separator: `;`

### 4. Pipeline (Makefile)
- `make install` - install dependencies
- `make run` - execute extraction
- `make test` - run unit tests
- `make check` - validate output file exists and has content

### 5. Error Handling
- Handle HTTP 401 (invalid/missing token)
- Handle HTTP 404 (project not found)
- Handle network errors
- Validate response structure
